# Local Development

<webui-page-segment>

Run Vocal Bin. The script lists any missing tools before building. Rust build output goes to `D:\CargoTargets` on Windows, or `~/CargoTargets` elsewhere.

Run Vocal Bin at http://localhost:8111

```pwsh
./PowerShell/RunLocal.ps1
```

Run on a different port

```pwsh
./PowerShell/RunLocal.ps1 -Port 8211
```

Clean the Rust build, then run

```pwsh
./PowerShell/RunLocal.ps1 -clean
```

Build the Rust code without starting the site

```pwsh
./PowerShell/RunLocal.ps1 -PreBuildOnly
```

</webui-page-segment>

# Build Tools

<webui-page-segment>

Format Rust code

```pwsh
cargo fmt
```

Lint Rust code

```pwsh
cargo clippy
```

Run Rust tests

```pwsh
cargo test
```

Build for release, the same as CI. Output goes to `webapp/dist`

```pwsh
Push-Location webapp
trunk build --release
Pop-Location
```

</webui-page-segment>

# Minified Files

<webui-page-segment>

The browser loads the minified files, so a change has no effect until its min file is regenerated. Commit both files.

Regenerate `webapp/css/app.min.css` after editing `app.css`

```pwsh
esbuild --minify webapp/css/app.css --outfile=webapp/css/app.min.css --allow-overwrite
```

Regenerate every `.min.js` in `webapp/wc` after editing a component

```pwsh
Get-ChildItem webapp/wc -Filter *.js | Where-Object { $_.Name -notlike '*.min.js' } | ForEach-Object {
    $minFile = $_.FullName -replace '\.js$', '.min.js'
    esbuild --minify --legal-comments=inline $_.FullName "--outfile=$minFile" --allow-overwrite
}
```

</webui-page-segment>

<webui-page-segment>

The page plays the synthesizer from `webapp/root_files/vocal-synth.wasm`, so a change in `synth/` has no effect until it is rebuilt. Commit the wasm with the Rust change.

Test and rebuild the speech synthesizer

```pwsh
cargo test -p vocal-synth
./PowerShell/BuildSynth.ps1
```
